# Implemented Features
## T-04: Implement Seller Portal
This feature allows the seller to login and create shipment
orders by entering goods details, weight, volume, pickup and
drop-off addresses and receiver information. System auto-assigns
RouteID and calculates Estimated Delivery Time (Today + 3 days)
once payment is confirmed. Seller can view own shipments only
and manage their profile.
