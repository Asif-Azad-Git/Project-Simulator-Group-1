# Implemented Features
## T-04: Implement Seller Portal
This feature allows the seller to login and create shipment
orders by entering goods details, weight, volume, pickup and
drop-off addresses and receiver information. System auto-assigns
RouteID and calculates Estimated Delivery Time (Today + 3 days)
once payment is confirmed. Seller can view own shipments only
and manage their profile.

**Status: Implemented**

## T-02: Implement Employee Dashboard
This feature allows the employee to login securely and access
the employee dashboard. Employee can verify shipment payment
status (Paid/Unpaid), assign shipments to carriers after
payment confirmation, update shipment and tracking info,
remove cancelled shipments, add or delete carriers,
add new routes and update personal profile.
Assigned to: HABIBUR RAHAMAN SYIMON (23-50644-1)
**Status: Implemented**

## T-03: Implement Carrier Dashboard
This feature allows the carrier to login securely and access
their assigned shipments. Carrier can view all shipments
assigned to their CarrierID, view route information including
origin and destination, update shipment tracking status
(Pending, In Transit, Shipped to Delivered), mark shipments
as Delivered to complete the delivery process, and update
personal profile information. System records a timestamp
for all status updates.
Assigned to: ADIB MAHBUB OMI (23-54633-3)
**Status: Implemented**

## T-05: Implement Customer Portal
This feature allows customers to register and login using
ClientID and password. Customer can view detailed shipment
information linked to their ClientID, track delivery status
and timeline of their shipments. System validates customer
details (name, email) during registration. Access is
restricted to own shipments only, cannot view others orders.
